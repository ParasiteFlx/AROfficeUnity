# AROfficeUnity

An augmented reality productivity application focused on 3D notes placed and managed within the user’s space. This is my bachelor’s thesis
project, designed for mobile phones running the Android operating system. The development took place within the ecosystems of the Unity
game engine and Google products. The ARCore SDK and the Unity ARFoundations package were used to create the AR experience. Further‑
more, this application integrates Firebase products for both the registration/login system and the logic for note distribution and persistence.
All 3D objects and textures were created by me using various open‑source software programs.

The following is a small tech demo for the app: https://www.youtube.com/watch?v=yuNgzXO4mXE 
This displays basic functionalities and the note distribution function by using two different phones and two different accounts.
