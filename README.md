# AROfficeUnity

EN: 

An augmented reality productivity application focused on 3D notes placed and managed within the user’s space. It was designed for mobile phones running the Android operating system. The development took place within the ecosystems of the Unity game engine and Google products. The ARCore SDK and the Unity ARFoundations package were used to create the AR experience. Furthermore, this application integrates Firebase products for both the registration/login system and the logic for note distribution and persistence. All 3D objects and textures were created by me using various open‑source software programs. 

The following is a small tech demo for the app: https://www.youtube.com/watch?v=yuNgzXO4mXE 
This displays basic functionalities and the note distribution function by using two different phones and two different accounts. 

RO:

Aplicație de realitate augmentată pentru productivitate care este axată pe notițe 3D plasate și gestionate în spațiul utilizatorului. Aceasta este destinată telefoanelor mobile cu sistem de operare Android. Dezvoltarea a avut loc în ecosistemele formate în jurul game engine‑ului Unity și în jurul produselor Google. Pentru crearea experienției AR a fost folosit SDK‑ul ARCore și pachetul Unity denumit ARFoundation. De asemenea această aplicație are integrată atât în sistemul de înregistrare/logare, cât și în logica de distribuire și de stocare persistentă a notițelor, produse din gama Firebase. Toate obiectele 3D și texturile au fost create de mine în diferite programe software open‑source.
